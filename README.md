# 侍道 ―SAMURAIDO―

体力と体幹を削り合う、2Dドット絵の剣戟アクションゲームです。ブラウザだけで遊べる単一の HTML ファイル（`index.html`）でできています。

## 遊び方

`index.html` をブラウザで開くと始まります。GitHub Pages を有効にすれば、URL を共有するだけで遊んでもらえます。

- **一人で挑む**：十人の剣客と続けて立ち合う十番勝負（命は五つ、コンティニューあり）
- **二人で対戦**：一台のキーボード、またはゲームパッド二つで対戦
- **フレンド対戦**：部屋コードを伝えて、離れた相手とオンラインで対戦
- **稽古**：基本の操作から「突き」「見切り」「踏み込み」まで

## 操作（一人用）

| キー | 動き |
|---|---|
| ← → | 移動（二度押しで踏み込み・退き） |
| Z | 斬る（長押しで溜め斬り） |
| X | 守る（当たる直前に押すと弾き） |
| Z＋X | 突き（ガード不能） |
| 相手の方向＋X | 見切り（突きに対して、当たる直前に） |

スマートフォンなどのタッチ操作にも対応しています。
